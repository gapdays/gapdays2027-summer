## Preparations before GAP Days

In preparation for these GAP Days please get your resources up to date.
Please note that this list will be updated as we go, as we find more things that need to be prepared.

- make sure you have a [GitHub account](https://github.com) (they are free)
- make sure you can log in to [HackMD.io](https://hackmd.io), e.g. via your GitHub account
- get/check access to the [GAP Slack](https://gap-system.org/slack), which has a dedicated GAP Days channel
- make sure you have a recent version of GAP installed (ideally 4.16.x or a development version built from the master branch)

In addition, we invite you to bring a travel drinking cup for use during coffee breaks,
to reduce the amount of waste we produce.
